# Oghenero Okikie: Portfolio

A one-page portfolio. No build step: edit `index.html` and the images, and the site updates.

## Edit
- Text and results: open `index.html` and search for `[` to find the placeholders (the result numbers in each case study).
- Images: replace the files in `images/` and keep the same file names.
- Colours: change the values at the top of the `<style>` block (`--acc`, `--sun`, and so on).
